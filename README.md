# Week 3: Supervised Machine Learning Models

## Dataset
**Bank Marketing Dataset**  
Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing)

## Project Summary
- Prepared the Bank Marketing dataset by handling missing values, encoding categorical features, and scaling the data.
- Trained and evaluated KNN, Decision Tree, and Logistic Regression classifiers, and conducted a separate Linear Regression experiment.
- Compared classification models using accuracy, precision, recall, F1-score, and confusion matrices.

## Best Model
**Decision Tree Classifier**

- Accuracy: **89.97%**
- Precision: **62.95%**
- Recall: **34.69%**
- F1-score: **44.73%**

Decision Tree achieved the highest accuracy, recall, and F1-score among the three classification models tested.

## How to Run
1. Install Python and Jupyter Notebook.
2. Clone or download this repository.
3. Install the required libraries using:

   `pip install -r requirements.txt`

4. Open `Week3_Supervised_Models.ipynb` in Jupyter Notebook.
5. Run the notebook cells from top to bottom. An internet connection is required to download the dataset.
